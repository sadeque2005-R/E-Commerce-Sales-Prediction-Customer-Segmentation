# E-Commerce Sales Prediction & Customer Segmentation

An end-to-end Machine Learning project analyzing real-world E-Commerce transaction data (5,000+ rows) to perform behavioral customer segmentation and accurate revenue forecasting.

---

## 🚀 Project Overview
In modern e-commerce, understanding customer lifetime value and accurately predicting future sales are vital for inventory management and targeted marketing. This project implements:
1. **Unsupervised Learning** (K-Means Clustering) for RFM-based Customer Segmentation.
2. **Supervised Learning** (Random Forest Regressor) for non-linear Sales Prediction.

---

## 📊 Dataset Features
The dataset contains 5,000 transaction records with the following columns:
- `order_id`: Unique identifier for each order.
- `order_date`: Timestamp of the transaction.
- `customer_id`: Unique identifier for the customer.
- `product_category`: Category of the purchased item (e.g., Beauty, Clothing, Electronics).
- `region`: Geographical region of the sale.
- `quantity`: Number of items purchased.
- `unit_price`: Price per unit.
- `discount`: Applied discount rate.
- `payment_method`: Mode of payment (Wallet, Card, COD, etc.).
- `delivery_days`: Number of days taken for delivery.
- `customer_rating`: Customer feedback score (1 to 5).
- `revenue`: Total calculated revenue.

## 📈 Key Methodology & Implementation

### 1. Customer Segmentation (RFM Analysis & K-Means)
- Grouped data by `customer_id` using **RFM metrics**:
  - **Recency:** Days since the last purchase.
  - **Frequency:** Total number of orders placed.
  - **Monetary:** Total revenue generated by the customer.
- Scaled features using `StandardScaler` and applied **K-Means Clustering ($k=3$)** to identify distinct customer groups (e.g., VIPs, Regulars, At-risk).

### 2. Sales Prediction (Random Forest Regressor)
- Extracted temporal features (`Day`, `Month`) from `order_date`.
- Switched from initial Linear Regression to **Random Forest Regressor** to effectively handle non-linear dependencies and prevent unrealistic negative predictions.
- **Model Performance:**
  - **$R^2$ Score:** `0.9989` (~99.9% accuracy)
  - **RMSE:** `26.72`
